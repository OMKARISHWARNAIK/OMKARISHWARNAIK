### 👨‍💻 Professional Overview

I am an early-career engineer and 2026 Computer Science graduate currently working at **ISG Labs**. My engineering focus spans two complementary domains:

1. **Enterprise Full-Stack Architecture:** Building resilient, high-concurrency backend services using **Java 17+, Spring Boot 3, and React**, with deep emphasis on **polyglot persistence** (balancing relational ACID constraints in PostgreSQL with high-throughput document stores in MongoDB), optimistic locking for race-free transactions, and sub-100ms real-time event streaming via STOMP WebSockets.
2. **Applied Artificial Intelligence & Computer Vision:** Researching and implementing practical machine learning systems—from multi-class plant pathology classification models correlating microclimate weather telemetry, to neuroevolutionary genetic algorithms (NEAT) that autonomously optimize neural network topologies.

I prioritize clean architecture, strict data integrity, measurable performance outcomes, and robust reproducibility across every codebase I engineer.
